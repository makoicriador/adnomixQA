# Feature: Service Providers - Customs Brokers Create

As an ADX Manager admin, I want to add a new customs broker from the
Customs Brokers index so that it becomes available for clearing shipments
without leaving the page.

URL: https://adxmanager.dev/v2/service-providers/customs-brokers
("Add Customs Broker" button opens the create drawer)
Reached via: log in at /system-login -> /home -> /v2/home -> left nav
"Service Providers" > "Customs Brokers" > "Add Customs Broker".

## Acceptance Criteria

- Given the Customs Brokers index, when a user clicks "Add Customs Broker" and submits the form with Company Name, Street Address, City, State, Country, ZIP Code, Contact Name, Email, Telephone Number, and Cell Number filled in, then the customs broker is created, a "Customs broker created successfully." confirmation is shown, and it appears in the index list with the entered name, location, and contact.
- Given the Add Customs Broker form, when a user submits it without a Company Name, then a validation error ("The company name field is required.") is shown and nothing is created.
- Given the Add Customs Broker form, when a user submits it without a City, then a validation error ("The city field is required.") is shown and nothing is created.

## Notes

Tag this feature: `service-providers`, `customs-brokers`, `create`

Covered end-to-end in `tests/test_ServiceProviders_CustomsBrokers_Create.spec.ts`.
As with the Suppliers features, the heuristic (non-LLM) Planner fallback in
`agents/planner/plannerAgent.ts` only understands simple email/password
login flows, so this feature's `TestPlan` and the page-object code itself
were authored directly rather than generated by the regex heuristic.

Every field and selector in `pages/CustomsBrokersPage.ts` was confirmed
against the live app independently (not assumed to match Suppliers or
Freight Forwarders, despite the similar-looking form). Non-obvious findings:

- Unlike Freight Forwarders, **Cell Number is marked "*" (required)** here.
  Every "*" field fails gracefully server-side — no hidden required field
  and no unhandled-500 field, same clean behavior as Freight Forwarders,
  unlike Suppliers.
- On a successful create, this section stays on the index (same as
  Suppliers) — unlike Freight Forwarders, which redirects to the new
  record's detail page.
- The index's Location column here is "{city}, {state}, {country}" — a
  third, different format from both Suppliers ("{state}, {country}") and
  Freight Forwarders ("{city}, {country}").

See `.agent-memory/project_conventions.md` for the full cross-feature
comparison table of these per-section differences.
