# Feature: Service Providers - Suppliers Index

As an ADX Manager admin, I want to search and filter the Suppliers list so
that I can quickly find a supplier and export the current view.

URL: https://adxmanager.dev/v2/service-providers/suppliers
Reached via: log in at /system-login -> /home -> /v2/home -> left nav
"Service Providers" > "Suppliers".

## Acceptance Criteria

- Given the Suppliers index, when a user searches by an existing supplier's name, then only matching suppliers are shown.
- Given the Suppliers index, when a user searches by an existing supplier's contact name, then only matching suppliers are shown.
- Given the Suppliers index, when a user searches by an existing supplier's location, then only matching suppliers are shown.
- Given the Suppliers index, when a user searches by an existing supplier's email, then only matching suppliers are shown.
- Given the Suppliers index, when a user filters by Status = Active, then only active suppliers are shown.
- Given the Suppliers index, when a user filters by Status = Inactive, then only inactive suppliers are shown.
- Given the Suppliers index, when a user filters by Status = Active and Inactive together, then the result count equals the sum of the two single-status filters.
- Given a Status filter is applied, when a user also searches by a supplier name, then the result set is narrowed further, not reset.
- Given the Suppliers index, when a user clicks Download CSV, then a CSV file downloads containing a header row and the current result set.
